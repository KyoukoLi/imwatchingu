# 私生模拟器（H5）

一个单文件 H5 文字模拟游戏：你扮演一名追逐偶像的私生/代拍，在「再赌一把」和「见好就收」之间推骰子。

> 本游戏纯属虚构，所有角色均为虚构的成年人物，与任何现实人物无关。请勿模仿游戏内任何行为。

## 怎么玩

- 直接用浏览器打开 `index.html` 即可（手机/电脑均可，竖屏体验最佳）。
- 或者任意静态服务器托管，比如：

```bash
cd sisheng-simulator
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

- 进度自动存档在浏览器 localStorage，关掉页面下次可以继续。

## 核心规则速览


| 数值    | 说明                                                                                  |

| 资金    | 跟机、买行程都要钱；卖素材回血。**永远不会变成负数**——没钱了只剩两条路：打零工，或打电话找妈妈要（每次 +¥2,000）。第三次开口 = 「第三通电话」破产结局 |
| 体力    | 每天恢复 60，行动消耗体力                                                                      |

素材分 5 级，越界才暴利；8 个结局，5 个是 BE。祝你回头是岸。

## 几条重要机制

### 偶像日程系统（v2 核心）

他有一张连贯的日程表，所有行程从日程派生，不再每天随机刷：


| 阶段    | 持续    | 特点                        |
| ----- | ----- | ------------------------- |
| 休整期   | 2-3 天 | 行程稀少，适合打工回血、清库存           |
| 练习期   | 2-3 天 | 公司楼下/练习室是主战场              |
| 本市录制  | 2-3 天 | 录制点+剧组酒店双线                |
| 外地行程  | 3-4 天 | 出发日可跟机→进入**远征模式**         |
| 新歌宣传期 | 4-5 天 | 公演/晚会/音乐节连轴转，**素材溢价 30%** |
| 演唱会   | 1 天   | 中后期解锁，一年里最大的行情日           |


- **远征模式**：出发日跟机过去（或中途飞过去），接下来几天你就在外地——外地酒店蹲守出货率高、竞争少，最后一天还能跟他同班机回程；外地住宿每晚 ¥250 自动结算
- 他飞走的日子，本市就是真的没行程，别硬蹲
- 每天日结面板会给出**明日风向**，提前规划要不要留钱留体力

### 其他

- 每条行程情报**当天只能行动一次**，用过就没了
- **跟机和酒店蹲守会花掉一整天**
- 每天结束有**日结面板**（收支/风险/素材汇总），手动确认后才进入下一天
- 粉群不只是看戏：可以**拼车**（外勤花费减半）和**接代拍单**（当天出指定等级素材自动结款）
- 连续两天空军后，下一条情报可信度会高很多（保底）
- 早晨可能发生随机事件；蹲点过程中也会随机插入小插曲（私生抢机位、辅警盘查、小粉丝求图……）
- 签售会一天只能去一次，错过自动排下一场

### 晚间突发事件（收工后随机触发）

每天收工后约 1/3 概率撞上突发剧情，全是大瓜和离奇向（部分为一局一次）：

- 💣 深夜撞破他接神秘女生上车——卖营销号炸超话 / 自己收藏 / 当没看见
- 🌉 凌晨江边撞见他和「嫂子」十指相扣散步——拍实锤 / 跟上去看她是谁 / 把江边让给他们
- 📍 闲鱼黑产卖磁吸 GPS——装上保姆车后**三天行程全透明**，但每天都可能被洗车房洗出来报警
- 🚬 后台后巷撞见他蹲着抽烟——拍人设核弹 / 默默退出 / 递上你的打火机（他会记住你）
- 🚄 高铁上拍到他和知名私生共享耳机——挂超话引爆粉圈内战 / 卖给对家 / 心态崩了
- 📱 候机厅前排，他的微信屏幕正对你的长焦——拍下 Lv5 聊天记录（可能直接撞破他的秘密）
- 🥊 公司侧门撞见他和队长推搡互呛——录视频 / 群里口述吃瓜 / 走开
- 📷 同担私生上手抢你相机——当街开打 / 忍 / 假装报警（「立法委员来了！」）
- 🍾 跟他进没有招牌的会所——目击顶流跑调唱《2002年的第一场雪》
- 🔮 天桥算命摊：「追星莫追命」——花 ¥100 换次日蹲点必中的祝福
- ❤️ 疑似他的小号给你的图点了赞
- 🐱 江边偶遇他独自喂流浪猫
- 🪪 捡到他遗失的工作证——收藏 / 归还 / 挂闲鱼
- 📸 初代大站退圈，半价传你「衣钵」镜头
- 🍺 被醉酒私生当成「绯闻女主」当街开撕

部分事件会与他的隐藏秘密联动（撞破恋情/争执时可能直接获得线索）。早晨还可能遇到：公司内鬼卖内部行程表、他托梦劝你「今天别来了」、营销号高价约稿收黑料……
